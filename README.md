# teak-sh/homebrew-tap

The Homebrew tap for [teak](https://teak.sh): Linux dev boxes for you and
your coding agents.

```sh
brew install teak-sh/tap/teak
```

It installs the `teak` CLI for macOS on Apple silicon and for 64-bit Linux
(Homebrew on Linux), with its bash, zsh and fish completions. Each release's
archives and their `SHA256SUMS` are this repository's GitHub release of the
same version; the formula is `Formula/teak.rb`.

To upgrade: `brew update && brew upgrade teak`.
